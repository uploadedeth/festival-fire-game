🚀 Integration Instructions

For Next.js:

1. Deploy this game to GitHub Pages

2. Use the iframe with the GitHub Pages URL

3. Listen for postMessage events from the game

4. Send commands using postMessage API

📨 Available Messages

Send to game: RESTART_GAME, GET_GAME_STATE, MUTE_AUDIO, UNMUTE_AUDIO

Receive from game: GAME_READY, GAME_STARTED, GAME_ENDED, SCORE_UPDATE, FIRE_EXTINGUISHED, GAME_STATE
